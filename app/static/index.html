CLOUD KEY CONNECTION

Connect UniFi Network

Local HTTPS connection. Nothing is changed on your switches.

Use a key from Network → Integrations on the Cloud Key. Official key mode includes switchport status, speed and PoE enabled; for PoE watts, VLAN profiles and connected-port details, choose a local account instead. Site Manager keys are different.

A local read-only / limited-privilege account is recommended. Two-factor cloud logins may not work with the local API.

Disabling certificate verification permits interception of API credentials. Only use on a trusted management LAN.
